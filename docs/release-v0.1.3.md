# 晒衣绳 v0.1.3 · Windows 预览版

截图，挂起来。把截图夹在桌面的晒衣绳上，随时打开、标注、复制或拖拽分享。

## 下载

- **Clothesline-Setup-0.1.3-x64.exe**：安装版，推荐日常使用，可选择安装目录并创建桌面快捷方式。
- **Clothesline-Portable-0.1.3-x64.exe**：便携版，下载后双击运行；数据仍保存在本机应用数据目录。
- **SHA256SUMS.txt**：两种可执行文件的 SHA-256 校验和。

适用于 Windows 10 / 11 x64。两种程序各约 106 MB，已包含运行环境，不需要安装 Node.js、npm 或 .NET。

## 三步开始

1. 打开程序，桌面出现晒衣绳，系统托盘出现 C 图标。
2. 按 **Ctrl + Shift + 2**，拖动选区，松开后截图自动挂上去；Esc 取消。工具栏也支持全屏和窗口截图。
3. 点击截图预览和标注，先「保存标注」，再复制或拖动 ↗ 分享。退出请右键系统托盘图标 →「退出」。

## 已提供

- 区域、全屏、窗口截图，默认选中主显示器。
- 木夹纸卡界面，拖动排序、固定、收纳及挂回。
- 画笔、箭头、文字、高亮、马赛克，撤销与重做；原图保留。
- 复制图片、PNG 文件拖放、另存为，删除到系统回收站。
- 快捷键、显示器、顶部 / 底部、置顶、自动复制与开机启动设置。
- 黑白几何 C 图标；托盘单击或双击显示绳子，右键打开菜单。
- 修复关闭截图、预览、设置及退出时访问已销毁窗口导致的异常；取消后迟到的截图结果会被丢弃。

## 预览版说明

本版本未做代码签名，Windows 可能显示未知发布者，请核对发布来源和校验和。目前只有一根绳子，最多同时挂 80 张；没有 OCR、搜索、云同步、多绳子或自动更新。

保护内容和最小化窗口可能无法捕获，窗口捕获可能缩小。微信、QQ、浏览器的文件拖放支持取决于接收应用，失败时可改用复制粘贴。混合 DPI 多显示器、实际跨应用拖拽、安装后的开机启动及长时间运行仍需更多人工验收。

已进行真实 Electron 窗口 / IPC / Canvas 标注与原图保留、取消截图、关闭退出回归检查；已核对打包源码和图标与项目文件一致。文档展示的是实际界面，示例内容为虚构便签。
