# 晒衣绳 v0.1.4 · 公开测试版

截图，挂起来。把截图夹在 Windows 桌面的晒衣绳上，需要时打开、标注、复制或拖拽分享。

## 这次发布

本版承接 v0.1.3，重新生成安装版和便携版，并补充公众号正文、横版封面、四步功能海报和实际界面说明。核心功能保持一致，没有新增 OCR、云同步或其他截图能力。

## 下载

- **Clothesline-Setup-0.1.4-x64.exe**：安装版，推荐日常使用。
- **Clothesline-Portable-0.1.4-x64.exe**：便携版，下载后双击运行，数据仍保存在本机应用数据目录。
- **SHA256SUMS.txt**：两种可执行文件的 SHA-256 校验和。
- **Clothesline-WeChat-Materials-0.1.4.zip**：公众号文案、封面、功能海报、实际截图和配图说明。

支持 Windows 10 / 11 x64，已包含运行环境，不用安装 Node.js、npm 或 .NET。

## 开始使用

1. 打开程序，桌面出现绳子，系统托盘出现 C 图标。
2. 按 **Ctrl + Shift + 2** 拖动选区，松开后自动挂绳，Esc 取消。工具栏也可截取全屏或窗口。
3. 点击卡片预览、标注；先「保存标注」，再复制或拖拽 ↗ 分享。右键托盘 C 图标 →「退出」。

还支持卡片排序、固定、收衣服与收纳箱恢复，画笔、箭头、文字、高亮、马赛克，原图保留，另存为和删除至回收站。

## 当前范围

这是公开测试版。安装包未签名，Windows 可能提示未知发布者，请核对来源和校验和。只有一根绳子，最多同时挂 80 张；区域截图在选定显示器内完成，没有 OCR、搜索、多绳子、云同步或自动更新。

保护内容或最小化窗口可能无法捕获，窗口捕获可能缩小。不同应用的文件拖放支持不同，失败时可复制粘贴。混合 DPI 多显示器、开机启动及长时间运行仍需实际使用反馈。
